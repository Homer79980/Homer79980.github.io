QUICK EXPORT / 1.0.2

把 Photoshop 当前画面，快速导出到指定路径。

快速导出是一个轻量 Photoshop UXP 面板。选择一次输出文件夹和格式，之后点击一个按钮就能导出当前可见画面；支持 PNG 与 JPEG，文件重名时会自动编号。

一个 CCX，完成当前画面导出

双击 CCX，通过 Creative Cloud 完成本地安装；重启 Photoshop 后，从“窗口 > 扩展功能（UXP）”打开“快速导出”。插件只访问你主动选择并授权的输出文件夹。

01 / PATH

选择一次输出文件夹

使用 Photoshop 文件夹选择器授权目录，插件会记住持久令牌，下次打开无需重新寻找路径。

02 / FORMAT

PNG 和 JPEG 随时切换

格式选择和导出按钮保持在同一排，当前选择会被记住，扩展名会自动匹配输出格式。

03 / CURRENT VIEW

导出当前可见合成

插件通过 Photoshop 副本导出当前画面，不改变原 PSD/PSB 文档，也不覆盖正在编辑的文件。

04 / FEEDBACK

结果直接显示在面板

导出中、成功和失败状态都显示在按钮上方；成功后会给出实际文件名，便于确认是否完成。

INSTALLATION

三步开始使用

普通使用者只需要 CCX；开发者也可以把源码包解压后通过 UXP Developer Tool 加载。

01 / DOWNLOAD

下载并安装 CCX

下载 v1.0.2 CCX，双击后在 Creative Cloud 中选择本地安装。

02 / OPEN

打开 Photoshop 面板

重启 Photoshop，从“窗口 > 扩展功能（UXP）”打开“快速导出”。

03 / EXPORT

选择路径并导出

点击“选择”授权目录，选择 PNG 或 JPEG，再点击“导出当前画面”。

04 / SOURCE

查看源码和校验值

Release 同时提供源码 ZIP 与 SHA256SUMS.txt，便于审计和离线留档。
