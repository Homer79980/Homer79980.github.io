PS OFFLINE MASK / 0.1.0

在 Photoshop 里，把背景干净地拿掉。

离线抠图优先在本机分析透明、棋盘格、纯色与近纯色背景，建立连续 Alpha，并清理绿幕、蓝幕和白底造成的边缘残色。复杂图片可以接入视觉模型提供主体先验，但最终质量门和边缘合成都留在本地完成。

CURRENT RELEASE离线抠图 0.1.0Photoshop 25.0+
CCX · SHA-256 可校验
01 / DETECT

先判断背景类型

透明图直接沿用原 Alpha；纯色与近纯色图从画布边界估计背景分布，并识别与外边缘不连通的内部孔洞。

02 / MATTE

生成连续 Alpha

颜色距离、连通区域和主体先验共同约束蒙版，边缘保留抗锯齿与半透明过渡，不只输出生硬的黑白轮廓。

03 / CLEAN

清理屏幕色污染

对绿幕、蓝幕和白底边缘做受控去色，使用可靠主体颜色重建半透明边缘，减少亮边和绿色残线。

04 / VERIFY

多背景检查后应用

在透明、白、黑和自定义背景上检查结果；低置信度候选会停在预览或精修阶段，不静默写回图层。

INSTALLATION

安装与升级

先停止并移除旧实例，避免 Photoshop 同时加载两个版本。

01 / DOWNLOAD

下载并校验

从 v0.1.0 Release 下载 CCX；需要校验时，对照同一 Release 中的 SHA256SUMS.txt。

02 / INSTALL

先双击 CCX

让 Creative Cloud 完成安装，重启 Photoshop 后从“增效工具”菜单打开“离线抠图”。

03 / DEV LOAD

未签名包的备用安装

若 Creative Cloud 拒绝安装，把 CCX 复制并改名为 ZIP，解压后在 UXP Developer Tool 中 Add Plugin，选择根目录的 manifest.json，再点击 Load。

04 / UPDATE

升级不覆盖旧目录

在 UXP Developer Tool 中 Stop 并移除旧版本，再加载新目录。菜单中应只保留一个“离线抠图”入口。

WORKFLOW

从当前图层到透明结果

所有计算先进入预览，点击“应用”前不会修改当前图层。

AI ASSIST

AI 负责理解主体，本地算法负责像素边缘。

普通多模态大模型可以判断主体位置、背景类型和疑难区域，但不能仅靠文字回答生成可靠的 2048×2048 Alpha。插件只接受结构化的主体先验或可验证 Alpha 候选，再与本地色度键、连通性、边缘重建和质量门合并。没有配置 AI 时，纯色背景流程仍可完全离线运行。
